2. What the app does

The app lets family members share their live location with each other, view location history, set up notifications for arriving at or leaving places ("geofences"), and request another family member's current location on demand. It also lets any signed-in user create or join a temporary group — a time-limited location-sharing circle (for example, a trip or event) that shares only current position, not history, and is automatically deleted once it ends.

5. Temporary groups — how they end

A group's creator picks, at creation, what happens when it ends: everything is deleted immediately, it goes read-only for a short grace period before deletion (during which the creator can extend it), or the member list is kept as a memento while location data is still deleted. Groups also have size, duration, and count limits that may change over time. Anyone in a group may share its join code with others (recruiting isn't limited to the creator); only the creator can rotate the code or end the group early.
